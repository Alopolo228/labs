# Задание  
Реализуйте приложение с GUI (приложения-игры допускается делать с использованием TUI-пакетов) по своему варианту. Можно изменить задание на собственную тему, согласовав с преподавателем. Требования:
приложение должно быть написано с применением ОО парадигмы
исключительные ситуации должны обрабатываться с использованием собственных исключений
GUI/TUI фреймворки не должны повторяться в группе  
# Описание  
1. Импортируем библиотеки (sqlite3, datetime, sys, PySide6.QtWidgets, PySide6.QtCore, PySide6.QtGui)  
2. Создаём классы исключений (FinanceError, InvalidAmountError, EmptyDescriptionError, DatabaseError)  
3. Создаём класс Database для работы с базой данных SQLite  
4. В методе init_db создаём таблицу expenses (id, amount, description, category, date)  
5. Создаём метод add_expense для добавления расхода в БД  
6. Создаём метод get_all_expenses для получения всех записей  
7. Создаём метод delete_expense для удаления записи по id  
8. Создаём метод get_statistics для получения общей суммы и группировки по категориям  
9. Создаём класс FinanceTracker, наследник от QMainWindow  
10. В конструкторе инициализируем БД, список категорий, вызываем init_ui, refresh_table, update_statistics  
11. В методе init_ui: создаём окно 900x600 с заголовком "Финансовый трекер расходов"  
12. Создаём левую панель с полями: сумма, описание, категория (выпадающий список), дата  
13. Добавляем кнопку "Добавить расход" с привязкой к методу add_expense  
14. Создаём правую панель с группой "Статистика" (QLabel для общей суммы и QTextEdit)  
15. Создаём группу "История расходов" с QTableWidget на 5 колонок  
16. Добавляем кнопки "Удалить выбранное" и "Обновить"  
17. В методе add_expense: получаем данные, проверяем валидность, вызываем db.add_expense, выводим сообщение, очищаем поля, обновляем таблицу и статистику  
18. В методе delete_expense: получаем ID выбранной строки, подтверждение удаления, удаляем запись, обновляем таблицу и статистику  
19. В методе refresh_table: получаем все расходы из БД, заполняем таблицу  
20. В методе update_statistics: получаем общую сумму и суммы по категориям, обновляем надпись и текстовое поле  
21. Создаём метод refresh_all (обновить таблицу и статистику) и clear_inputs (очистить поля)  
22. Запускаем приложение через QApplication и app.exec()
