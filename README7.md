# Задание  
Перепишите свой вариант ЛР №6 с использованием классов и объектов. Задание то же, вариант GUI фреймворка возьмите следующий по списку. Для успешной сдачи в коде должны присутствовать:
использование абстрактного базового класса и соотвествующих декораторов для методов,
иерархия наследования,
managed - атрибуты,
минимум 2 dunder-метода у каждого класса.  
# Описание  
1. Импортируем библиотеки (wx, listmix, modules2)  
2. Создаём класс BankFrame, наследник от wx.Frame  
3. Создаём конструктор с заголовком "Банковские услуги" и размером окна  
4. Создаём панель и вертикальный главный sizer  
5. Создаём группу "Параметры услуги" со статическим боксом  
6. Добавляем выпадающий список для выбора типа услуги (Кредит/Рассрочка/Вклад)  
7. Добавляем поля ввода: сумма, срок, процентная ставка  
8. Создаём кнопку "Рассчитать" с привязкой к методу on_calculate  
9. Создаём группу "Результаты расчета" с многострочным текстовым полем  
10. Создаём группу "График платежей" с таблицей (ListCtrl) с тремя колонками  
11. Создаём кнопку "Сохранить отчет в Excel" (изначально неактивна)  
12. В методе on_calculate: получаем данные из полей ввода  
13. В зависимости от типа услуги создаём объект Credit, InstallmentPlan или Deposit  
14. Вычисляем общую сумму и ежемесячный платёж  
15. Выводим результаты в текстовое поле  
16. Заполняем таблицу графика платежей построчно  
17. Активируем кнопку экспорта  
18. Обрабатываем ошибки ввода через wx.MessageBox  
19. В методе on_export: сохраняем отчёт через ReportExporter.save_to_excel  
20. Создаём класс BankApp, наследник от wx.App  
21. В методе OnInit создаём и показываем главное окно  
22. Запускаем приложение через app.MainLoop()
